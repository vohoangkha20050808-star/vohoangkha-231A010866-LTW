# PhoneStore (bản chạy thẳng trên trình duyệt) – tháng 10/2026

Đồ án Lập trình web – Võ Hoàng Kha – MSSV 231A010866 – ĐH Văn Hiến.

**Cách mở:** bấm đúp file `index.html`. Không cần cài đặt gì.
Dữ liệu lưu trong trình duyệt (localStorage). Muốn xóa dữ liệu làm lại: F12 → Application → Local Storage → Clear.
